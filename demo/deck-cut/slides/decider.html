Who decides

One function decides: share, hold or discard. The scope check decides who may hear it.

INPUT

The change

Text and author room. Kind: contract, decision, verdict, private note, noise

DECIDER

rules-v0, 1.7 ms

Verdict and a confidence. Targets come from the access matrix, never from the text

SCOPE CHECK

Allowed, or refused

Per target room. A fooled verdict still hits the wall

AUDIT

One row

Verdict, confidence, allowed, reason, full text. A human override is a training row

Built today

  • Rules decider, in process, 1.7 ms per change
  • The other agent has it on its next step: 2.9 s median over five runs, set by its own cadence
  • The same function signature takes a trained model later; nothing else changes

Why it is not trivial

  • Untrusted text goes in, so an injected line can move the verdict
  • The answer is not trusting the text: the scope check refuses, and the audit shows the tilt
  • Every refusal is recorded as deliberately as every share
