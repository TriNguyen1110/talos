Press run and narrate; the page does the work. If it stalls, open the workflow page and finish from the saved run. Run the failure first if you use the two-terminal demo instead. In beat two the tool call must be visibly unrelated to the change: it is a write of Frontend's own client. Numbers measured 2026-09-27, 14:56 to 15:36 PDT, one laptop, five runs each way.
