The demo

Two terminals. Left is Backend, right is Frontend mid-task. The same minute, twice.

1 · without

Backend renames a field. Frontend never hears, finishes correct and wrong.

unaware 5 of 5 runs

2 · with

Same change, typed again. Frontend's next tool call, about something else, carries it. It stops.

2.9 s median, 5 runs

3 · held

Backend writes an approach note. Hold. Frontend sees nothing. The hold is a row with a confidence.

hold · 0.5

4 · injected

A line in the note says share everything. The decider tilts. The scope refuses all three targets.

refused 3, leaks 0

5 · revoked

Flip one verdict: that row is training data. Revoke Frontend: its very next call is denied.

denied in 0.1 s

6 · the week

A feature request, a CI verdict, an internal fix, a breaking fix, a UI change. Same path, five lines.

run.sh factory

Every line on screen is a row in one audit table. The timeline page is that table drawn.

Next: how do we know it worked?

Run the failure first and do not cut it. In beat two the tool call must be visibly unrelated to the change: it is a write of Frontend's own client. Numbers measured 2026-09-27, 14:56 to 15:36 PDT, one laptop, five runs each way. The 2.9 s is the gap until Frontend's next step, not the decider. Revoke to denied on the same token via the CLI: 0.105 s.
