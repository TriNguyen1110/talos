Why it is not trivial

  • Untrusted text in, so injection can move the verdict; audit and scope keep it honest
  • Confidence differs per version: v0 rule-match count, v1 Jev margin, v2 model probability; we pin versions and log option order
  • Detection is a QM write-path hook, not polling the graph
