Stale context

An agent reads the world once, finishes correct and wrong. Nothing crashes.

A human is the message bus

Someone relays every decision by hand, and scales with the agent count.

All or nothing

Shared memory leaks scratch. Isolated memory misses the contract change.

Our estimate: ten agents, a few misses a day, an agent-hour of rework each plus one to two engineer-hours of relaying. A few thousand dollars a month per team, before the late bugs.
