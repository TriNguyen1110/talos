Q1 · What crosses between the rooms?

Contracts, decisions and verdicts cross. Scratch and approach notes stay home.

Program Manager

Scopes work, accepts results. Stays home: prioritisation scratch.

Frontend Engineer

Screens, UI contract. Stays home: approach notes, half-built ideas.

Backend Engineer

API and database. Stays home: approach notes, migration drafts.

QA Engineer

Reads every room's outputs, writes verdicts only.
